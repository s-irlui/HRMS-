# Wireframe Notes

PulsePeople is a tool-first HR workspace, not a landing page.

## Mobile Screens

- Sidebar becomes stacked navigation.
- Tables become horizontally scrollable.
- Forms sit below records and approval queues.
- Dashboard hero remains first, with stats underneath.

## Primary Views

- Dashboard: role-aware KPIs, notifications, attendance snapshot.
- Employees: searchable records, onboarding form, sensitive-field gating.
- Leave: employee request form, manager/HR approval queue.
- Attendance: clock in/out plus scoped attendance table.
- Departments: admin configuration and staffing distribution.
- Reports: CSV exports and headcount analytics.
- Audit: admin-only write operation log.
